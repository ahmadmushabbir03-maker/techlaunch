# TechLaunch

## IT Career & Skill Readiness Platform

TechLaunch helps IT professionals and students understand
technology skills, track their readiness, manage projects,
and prepare for technology careers.

### Technology Stack

- Node.js
- Express.js
- MongoDB / Azure Cosmos DB MongoDB API
- Azure App Service
- Terraform
- Jenkins CI/CD
- GitHub

### DevOps Architecture
